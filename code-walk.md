# Code Walk — Assignment 00: Setup

**Due Tue Sep 22, 5:00 PM PT · upload to Canvas · 10 points**

This week's walk is a warm-up, and it is deliberately tiny. Its only job is to prove your recording
setup works and to get you used to talking over your own screen — because every week after this one
asks for a real one.

## What to show (~1 minute)

1. **Your change.** Open `Greeting.java`, point at `STUDENT_NAME` with your name in it, and say what
   `message()` returns because of it.
2. **The test going green.** Run `./gradlew test` on camera and show `messageNamesTheStudent`
   passing. Say in one sentence what that test is actually checking.
3. **One thing you had to look up.** Anything at all — a Gradle command, what `src/main/java` is
   for, why the folders are so deep. There is no wrong answer in week 1.

## How this is graded

**10 points, and the whole 10 is yours for doing it.** Record it, upload it, done. There is no
polish score and no penalty for restarting a sentence.

Marks come off in one case only: **no video, or a video that shows no code.**

**The grade is not the point — the feedback is.** You will get written comments back, and this week
they are mostly about your setup: whether we can hear you, whether the code is readable on screen,
whether the recording actually uploaded. Fix those now, while it costs nothing.

## Practical

- **Share your screen with the code visible** and talk over it. Slides are not wanted.
- Any recording tool is fine (Zoom, QuickTime, Panopto). Upload to Canvas — a link is fine if the
  file is large.
- Say your name at the start.
